About Throne

Throne is a free, read-only research tool for content creators. It helps a creator discover which video topics are already popular on YouTube so they can plan their own original videos.

What it does with the YouTube API
  • Searches public YouTube videos by keyword, language and date range (search.list).
  • Reads public video information: title, channel name, publish date, duration, view count and thumbnail (videos.list).
  • Shows the results in a ranked list so the creator can compare how well topics perform.
What it does not do
  • It does not upload, edit, delete, like, comment or subscribe on YouTube.
  • It does not access any YouTube account, private data or OAuth user data.
  • It does not download or re-host videos.

Throne also contains tools to draft scripts and voice-overs for the creator's own original videos. Those features are separate from the YouTube API.

Privacy Policy

Last updated: November 18, 2026

Data we collect. Throne does not require an account and does not collect personal information on a server. The app runs in the user's own web browser.

Data stored on your device. Settings, saved ideas and the user's own API keys are stored in the browser's local storage on the user's own device. This data is not sent to us. The user can delete it at any time by clearing the browser's site data.

YouTube API Services. Throne uses YouTube API Services. By using Throne you agree to be bound by the YouTube Terms of Service. Google's use of data is described in the Google Privacy Policy. Throne only requests public video data. Throne does not use OAuth, so no Google or YouTube account data is accessed or stored. Users can review and revoke access to apps connected to their Google account at https://security.google.com/settings/security/permissions.

Third-party services. Some optional features (text and voice generation) send the text the user writes to third-party AI services chosen by the user, such as Puter. Those services have their own privacy policies. Do not enter personal or sensitive information into those features.

Cookies and analytics. Throne does not use advertising cookies or tracking analytics.

Children. Throne is not directed to children under 13.

Changes. If this policy changes, the date above will be updated.
